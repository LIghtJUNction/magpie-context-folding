# 本地查看折叠效果

在插件仓库目录执行，输出路径必须是一个尚不存在的绝对路径，父目录须已存在：

```sh
bun src/cli.ts report --output /absolute/path/folding-effects.html
```

用浏览器打开生成的 HTML 即可。文件包含全部样式和交互，不使用网络、外部脚本、字体或图片。顶部可选择浅色或深色，以及辅助辨识和打印用的图形纹理；条形支持鼠标悬停和键盘 Tab 查看数值，也有可展开的数据表。

默认读取当前用户本机的归档与全局累计统计。插件使用自定义状态目录时，须在同一环境运行，例如：

```sh
MAGPIE_CONTEXT_FOLDING_STATE_DIR=/absolute/state/directory \
  bun src/cli.ts report --output /absolute/path/folding-effects-2.html
```

只看某个会话可加 `--scope S`，其中 `S` 是插件会话引导给出的能力值。不要分享该能力值，也不要把它写进文件名。HTML 内只显示“会话 1”等临时匿名编号，不包含能力值。报告本身不会列出可复制的会话标识。

## 如何读报告

- **当前归档快照**显示当前条目、独立折叠条目、明确 `keep` 的条目、历史层和分组数量。分组覆盖的子条目不会重复计入独立折叠数；`keep` 是明确保护标记，不等于全部未折叠条目。
- **最近决策**显示每个会话最后一次记录的固定原因名称，以及已记录的请求体字节比较。比较基线是在复用已有折叠之后、新增折叠之前，且没有新引导开销的请求；候选包含拟发送的引导与预算开销。未批准的候选会明确标注，不能当作实际发送结果。批准也不代表请求成功。最后决策没有前后字节证据时，显示未记录，不推算或补画。
- **费用证据**展示现有统计接口提供的条件下界及已核实比较次数。该金额取决于证明中的 token、价格、缓存和费用边界假设。当前证书必须覆盖同一任务全部新增工具调用、模型往返、合计输入输出与工具直接费用；历史累计保留原证据限制，不能升级为完整任务收益证明。`actualBillSavingUsd = null` 表示实际账单节省未知。
- **累计统计**包括批准批次、折叠次数、递归折叠、成功/失败/未核实请求、复用、读取和恢复。全局累计在清除归档后仍可能保留，不能和当前快照数量混为一谈。净减少 token 使用序列化 UTF-8 字节 / 4 估算，可能为负；它不是 tokenizer 实测，也不同于证书中的 token 下界。

每个会话的字节图使用自己的零起点刻度，适合比较该会话的基线与候选。不同会话之间应比较标注的数值。数据库字节数仅表示本地存储占用，不是网络请求体积。

## 从页面定位问题

每个会话的“下一步查什么”根据最后决策的固定原因给出检查项。例如阈值未达到时检查 `config` 中生效的 `threshold_tokens`；缺少新增成本边界时补齐工具调用、模型往返、合计输入输出和直接费用；候选不够小时检查引导、预算和恢复引用的总开销。

看到“没有更小候选”时，用同一状态目录的 `list` 和 `status` 检查标记、近期消息、最新文件保护及摘要长度。记录没有指出具体哪项阻止折叠，页面不会代替证据猜原因。未知原因或没有决策时明确显示“证据不足”，提示检查插件启用状态、状态目录和宿主工具声明；这些只是检查项，不是已经确认的根因。`config` 输出隐藏服务地址和脚本参数；不要把凭据或请求正文放进调试材料。

报告是生成时的快照。完成检查后，用新的输出文件名重新导出，再比较页面上实际记录的数值；没有逐次请求日志或时间趋势。

## 隐私与只读边界

报告仅读取现有统计和归档元数据，不读取内容块，不新增请求日志，不改变配置、标记、折叠状态或读取次数。没有安装状态时显示空报告，不创建状态数据库。

原文、摘要、路径、模型名、会话能力值、内容哈希、证书自由文本和未知原因的原值不会写入 HTML。文件仍包含使用计数与金额，分享前自行判断其可见范围。输出以 `0600` 权限独占创建，已有文件和符号链接均拒绝覆盖；重新生成时使用新文件名。

统计和归档元数据分别以只读快照读取；有并发活动时，两者可能略有差异。现有归档仅保存每个会话的最后决策，没有历史请求轨迹，报告不会伪造时间趋势。会话匿名编号只对当前文件有效。报告没有模拟数据选项；所有显示的计数来自本机记录，空数据保持为空。
