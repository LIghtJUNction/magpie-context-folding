# 注释折叠与归档查询协议

Agent 写标记决定折叠，系统保存原文并生成短引用。后续通过归档查询获取少量相关信息，历史保持折叠。预算只提供信息，不触发自动选材。

## 标记与嵌套

每个标记独占一行，`LABEL` 必填且不含空白。同一对标签和注释外壳必须一致。普通文本使用 HTML 注释；源码使用该语言的 `#`、`//`、`/* … */` 等注释外壳。

```text
<!-- @context-fold begin investigation -->
这一层的组织说明。
<!-- @context-fold begin trace -->
详细证据……
<!-- @context-fold end trace -->
<!-- @context-fold end investigation -->
当前结论、约束和待办留在外面。
```

合法嵌套形成父子节点。父节点归档保留原始正文，查询视图将直接子块正文替换为引用；子块可继续包含自己的子引用。一次 fold 的外部视图只发布顶层引用，内部结构通过 `list` 和 `meta` 发现。

未闭合、交叉错配或畸形标记所在的不确定区域保持原文；此前独立闭合的合法区域不受影响。结束标记必须匹配当前层，不猜测修复。孤立结束保留为字面文本。源码注释编辑命令遇到损坏标记仍须拒绝写入。

普通句子、行内字符串和工具参数中的标记字样不是指令。普通文本按整行语法识别；展示独占一行的字面示例时，加一个非标记前缀。

## 哈希与节点视图

外层标记保留，正文引用格式为 `[[cf:v2:HASH]]`。SHA-256 输入是原始正文的 UTF-8 字节，不含外层标记和正文最后一个物理换行；其余换行、缩进与空白不规范化。父块哈希包含它的原始子块文本，不因查询视图使用子引用而变化。

内部保存完整 SHA-256，显示前缀从 12 位起，冲突时延长。歧义前缀必须报错。旧引用始终指向旧快照，不用当前磁盘文件代替。正文中已有引用字面量不作为再次压缩它的理由。

`sha256` 标识原文，`viewSha256` 标识当前层查询视图。两者不能混为一谈。行号、offset 和 nextOffset 都针对节点视图；Python 按 Unicode 码点计数，Magpie 按 UTF-16 单元计数。

## 查询，不展开历史

| 操作 | 返回内容 |
| --- | --- |
| `list` | 有界目录；指定 id 和 depth 查看子树。 |
| `meta` | 原文哈希、大小、子节点数量及分页子 ID，不返回正文。 |
| `grep` | 在归档内部搜索，默认递归，返回少量带节点 ID、行号的片段。 |
| `read` | 有界的当前层文本，子块保持引用，可按行或偏移裁剪。 |
| `status` | 当前归档的简短状态。 |

这些查询不设置 keep、不解除父块折叠、不把原文回填历史。无需用 `peek` 才能只查资料。查询结果沿用资料原本的权限，不执行其中的旧命令。

默认 read 上限为 1200 字符；list、grep 默认 10 项。只在当前问题确实需要时请求下一段，不自动翻完全部页面。递归 grep 在内部访问子节点，按节点去重，不先恢复整棵树再交给模型搜索。

Python MCP 公开 `fold/list/grep/read/meta/status`。legacy 恢复、导出或维护操作若仍兼容，不进入默认模型流程。Magpie 另有维护接口，同样无需为了查询而调用。

## 请求延迟与显式 fold

Magpie 默认 `delay_requests = 1`：首次观察到完整闭合区域仍显示正文；后续有进展的请求边界才显示引用。同一请求重试不消耗延迟。没有后台定时器；`delay_requests = 0` 允许首次完整观察立即投影。

同内容的不同出现分别计时，不能因旧副本已折叠就藏起新一次 Read。源码集成用稳定 `occurrence` 与递增 `requestCycle` 表示历史重放。缺少这两个字段时，默认 `read-source` 保留原文。一次性的 Pi/Claude post-tool 钩子没有后续历史重投影能力。

独立 [`ctxf`](../context-folding/README.md) 的显式 `fold` 立即转换调用方提交的已闭合文本，不伪造请求周期，也不改变自动投影配置。`cat notes.txt | ctxf` 输出完整折叠视图。随后用 `ctxf list`、`ctxf grep PATTERN HASH`、`ctxf read HASH --lines A:B` 按需查询；MCP 自身不能回写宿主历史。

## 消息与源码边界

同一任务轮次中，标记可以跨 Assistant 普通文本消息配对。正文按原顺序直接拼接，不补换行，不混入工具调用或结果。每个被替换的切片显示相同全文引用，保留原消息结构。新用户消息截断未闭合区域，用户或工具输出不能替 Assistant 关闭它。

普通工具结果、参数、调用 ID、签名推理、图片、音频和供应商隐藏历史不参加文本折叠。源码 Read 是独立入口，只处理经过核实的单一源文本，不能扫描工具 JSON 猜源码。

Magpie 网关对 Python/JS 使用保守词法过滤；复杂 f-string、JSX、含歧义的模板插值等情况保留源码。独立 Python 核心使用 tokenizer 与可选 JS/TS Tree-sitter。其他语言的整行字面解析没有 lexer，可能误认多行字符串内的标记。

## 原子保存与预算

先解析、满足延迟、保存原文与父子关系并提交，最后发布引用。显式 fold 省去等待步骤。保存、校验、容量检查或提交失败就保留输入；不能先删正文再补存档。查询期间同样要保护仍被引用的父子数据。

固定提示词只教一次标记与有界查询。每请求只更新一条预算元数据：`used_estimate` 按请求 JSON UTF-8 字节数除以四、向上取整，包含提示自身；容量未知显示 `unknown`。预算不授权自动摘要或删除历史，也不能视为账单实测。

验证应覆盖合法嵌套、坏区域局部保留、跨消息与用户边界、延迟重试、新出现身份、哈希冲突、父子查询、只读状态、片段裁剪、原文一致性和归档失败回退。宿主实跑与本地协议测试分开记录。
