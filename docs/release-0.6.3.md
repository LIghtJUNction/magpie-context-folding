# 0.6.3：前置保留区重放修复与主动式上下文折叠术

折叠正文以箭头保留区开头时，恢复元数据出现在保留区之后。此前解析器只检查正文开头，后续请求会把投影再次归档，改变恢复哈希并重复累加折叠计数。

解析器与存储层现在共用引用识别逻辑，跳过保留区内的字面示例后检查恢复元数据。四种协议的连续重放保持投影、归档原文与折叠计数稳定；嵌套父块也能正确引用这类子块投影。

README 新增“主动式上下文折叠术”：Agent 在工作过程中主动整理已完成阶段的证据，将当前结论、约束、未解决问题与下一步留在外面，需要时精确恢复归档。说明技能与插件各自的职责，以及标记、实际折叠和用量收益之间的区别。

## 验证

- 本地类型检查、构建与 330 项测试通过。
- 新增四协议前置保留区重放回归测试，并覆盖包含前置保留区的嵌套投影。
- 实际 Magpie/Bun 隔离宿主的 9 次请求通过，使用本地模拟上游，覆盖原文归档、CLI 恢复、保留区与重放。
