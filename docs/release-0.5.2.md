# magpie-context-folding 0.5.2

本版改进长源码读取后的上下文投影与折叠指导频率，原始源码仍完整归档，可按需精确查回。

## 变化

- 唯一定位到当前问题所问的函数时，只把该函数及可确认的文件级字面量常量放进后续请求；歧义问题继续保留完整源码。未包含的定义可用提示中的归档 `grep/read` 查回。
- 对参数、局部变量遮蔽和可变文件级值采取保守处理，不把这些值误拼成文件级依赖。
- 连续指导没有触发折叠时，逐步降低重复指导频率；折叠成功或需要恢复引用时仍提供指导。
- 扩展 hook 结果和上下文指导退避的指标、状态保存与 Magpie 隔离宿主覆盖。

## 验证

- 本地完整检查：TypeScript 类型检查通过，Bun 测试 312 项通过、0 项失败，构建通过。
- Magpie/Bun 隔离 host smoke：29/29 请求到达本地合成上游，响应 hook 成功 29 次，失败和未验证均为 0；46,278 字节合成源码可精确恢复。
- 四种请求协议的本地合成源码投影基准中，定向请求为 1,086–1,177 B，完整源码请求为 127,340–127,439 B。该比较只测序列化 JSON 字节；未调用 Provider，不证明模型回答等价、真实输入 token、账单节省或任务提速。详见[基准与限制](cost-speed-quality.md#首次完整源码读取的函数定向投影本地合成未调用-provider)。

## 安装

```sh
magpie plugin add npm:magpie-context-folding@0.5.2
```

保留已有归档，避免同时加载同一插件的源码路径和 npm 包副本。
