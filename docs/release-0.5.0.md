# magpie-context-folding 0.5.0

本版将 Magpie 恢复入口改为现有终端中的 CLI，并修复多层归档、重放来源及查询性能。Python 独立核心与 SDK 随源码维护，根 npm 制品只发布 Magpie 插件。

## 变化

- 请求钩子注入简短系统指导，完整保留原宿主指令；原文先归档再折叠，仍只处理 Agent 明确标记的内容。
- 正确匹配的嵌套标记可保存每层原文；查询父节点时子节点保持短引用，可按需继续查询。
- 普通 `read/paste` 保持折叠状态；`read --restore` 显式返回完整原文并保护所选子树和全部父级。CLI 默认读完当前视图，`--limit` 提供有界分页，`list` 默认 JSON。旧导出参数、可见性与归档定位入口继续兼容。
- 修复 50,000 层合法引用链校验的栈溢出；保留循环拒绝及持久状态保护。
- 首次归档即保存来源范围，同请求重放不再增大归档或干扰会话配额调整。
- 无子节点的归档视图直接返回正文，避免叶节点搜索反复建立全库索引。
- 保留统计、HTML 报告、scope 隔离、Unicode/CRLF 精确回查和签名内容保护。
- 增加项目自身离线沙箱基准、Luna 编码试验、独立干净验收、可选日志摘要及有界交付反馈。

## 升级

```sh
magpie plugin add npm:magpie-context-folding@0.5.0
```

移除旧插件 options 中的 `recoveryToolName`。当前版本通过已声明且允许调用的 shell 工具执行 CLI；自定义终端名可用 `shellToolName` 配置。已移除的窗口预算配置不再有效。不要同时加载 npm 安装和本地源码两份相同插件。

Python `ctxf` 和根插件各自使用独立归档，不跨后端读取引用。已有归档应保留；不要通过删除数据库处理迁移错误。
