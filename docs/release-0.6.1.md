# 0.6.1：折叠与工具协议解耦

修复 Codex code mode 等工具封装下折叠被跳过的问题。此前插件仅在请求声明了白名单内的 shell 工具时执行折叠；间接执行器、命名空间、延迟加载工具以及无工具请求会被跳过。

现在折叠只依赖可解析的正文、完整标记、成功归档与净节省门槛，不再读取工具名称或工具选择来决定是否折叠。Chat、Responses、Anthropic 和 Gemini 共用这一行为，工具声明与调用限制保持原样。不完整的工具交换及宿主管理的历史仍按原规则保护。

原文先保存到归档，再发布带绝对路径的折叠视图。当前请求没有文件读取能力时，可稍后使用宿主文件工具或本地 CLI 恢复；不保证模型能在工具禁用期间自行读取。旧 shell_tool_name 配置兼容保留，不再作为折叠条件。

验证：运行 npm run check 与 npm run test:host。宿主测试使用实际 Magpie/Bun、隔离环境与本地模拟上游，工具名为任意包装器，检查折叠、局部保留、原文 SHA-256、CLI 恢复及重放。没有调用外部模型，不代表真实账单或回答质量验证。
